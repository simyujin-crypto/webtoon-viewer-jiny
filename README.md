# 웹툰 뷰어 (안드로이드)

PC용 `webtoon_viewer.py`를 안드로이드 앱으로 옮긴 프로젝트입니다.
화면(HTML/JS)은 PC 버전과 같은 구조이고, 파이썬 서버가 하던 일은 앱(Kotlin)이 대신합니다.

## APK 만드는 방법

### A. 안드로이드 스튜디오 (가장 간단)
1. 안드로이드 스튜디오 설치 후 `File > Open` 으로 이 폴더 선택
2. Gradle Sync 가 끝날 때까지 기다리기 (인터넷 필요)
3. `Build > Build Bundle(s) / APK(s) > Build APK(s)`
4. `app/build/outputs/apk/debug/app-debug.apk` 를 폰으로 옮겨 설치
   (폰에서 "출처를 알 수 없는 앱 설치" 허용 필요)

### B. 설치 없이 GitHub 에서 빌드
1. 이 폴더 전체를 GitHub 새 저장소에 올리기
2. 저장소의 `Actions > Build APK` 실행 (push 하면 자동 실행)
3. 완료 후 `webtoon-viewer-apk` 파일을 받아 압축을 풀면 APK

## 사용법
- 폴더 열기 / 압축파일(zip, cbz) 열기 / 이미지 직접 선택
- 파일 관리자에서 zip / cbz 를 눌러 "웹툰 뷰어"로 바로 열기
- 화면 한 번 탭: 메뉴 보이기/숨기기, 두 번 탭: 자동스크롤 시작/정지
- 두 손가락 벌리기/모으기: 확대/축소 (메뉴의 －, ＋, 폭 맞춤도 사용 가능)
- 세로 보기 / 가로 보기, 맨 위·중간·맨 아래, 전체화면
- 자동스크롤 중 볼륨 키(▲▼): 속도 조절, 자동스크롤 중 화면 꺼짐 방지
- 보던 위치와 확대/속도 설정은 자동 저장

## PC 버전과 다른 점
- rar / 7z 는 지원하지 않습니다 (zip, cbz 로 다시 압축해 주세요)
- 안드로이드 11 이상에서는 저장소 최상위나 Download 폴더 자체는 "폴더 열기"로 선택할 수 없습니다. 그 안의 하위 폴더를 선택하세요.
- 드래그&드롭, 마우스 휠, 단축키 대신 터치 조작을 씁니다.
